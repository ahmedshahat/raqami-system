# مراجعة شاشات موديول المقاولات

تمت مراجعة المسارات الفعلية في `Routes/web.php`، والمتحكمات، وكل قوالب `Resources/views`. قاعدة القرار: بيانات رأس قصيرة تدخل في نافذة؛ الجداول والتحرير والمراجعة والاعتماد والطباعة تبقى في مساحة الصفحة.

| الشاشة أو العملية | القرار | التنفيذ |
| --- | --- | --- |
| عروض الأسعار / إنشاء عرض | نافذة | بيانات العرض الأساسية فقط؛ البنود في شاشة واسعة، والتحويل إلى مشروع في نافذة تجمع بيانات المشروع غير الموجودة في العرض. |
| قائمة المشاريع / إنشاء مشروع | عرض فقط | الإنشاء العادي يبدأ من عرض سعر مقبول. أُخفي زر الإنشاء المباشر، مع إبقاء `projects.create` و`projects.store` للإدارة والاستيراد والمشاريع القديمة. |
| تفاصيل المشروع | صفحة عمل | المشروع الناتج عن عرض يخفي المقايسة من المسار ويعرض العقد كخطوة تالية، مع رابط العرض الأصلي. المشروع القديم يحتفظ بمساره السابق. |
| تعديل المشروع | صفحة | يتضمن أعضاء الفريق والتواريخ والتفاصيل، لذلك أبقي التحرير الكامل. |
| المقايسة / إنشاء إصدار فارغ | نافذة | من تاريخ الإصدارات داخل شاشة المقايسة. يفتح الإصدار الجديد في مساحة المقايسة الواسعة بعد الإنشاء. |
| بنود المقايسة / الاستيراد والمراجعة / التوزيع المالي | صفحة | جداول بنود كثيرة، إدخال جماعي ومراجعة استيراد. |
| أكواد التكلفة / إضافة كود | نافذة | تحديث الجدول وخيارات الكود الأب فور الحفظ. |
| إنشاء وتعديل العقد واعتماده | صفحة | شروط مالية وأطراف ونسخة للمراجعة والطباعة. |
| قائمة الحصر / إنشاء حصر | نافذة | رقم وتاريخ وفترة وملاحظات فقط. تحديث القائمة وعرض جدول الحصر أسفلها. |
| جدول كميات الحصر واعتماده | صفحة | إدخال كميات وتحقق تراكمي واسع. |
| قائمة مستخلصات المالك / إنشاء مستخلص | نافذة | قياس معتمد وتاريخ وفترة واسترداد وخصومات. تحديث القائمة وعرض المستخلص أسفلها. |
| إنشاء مستخلص من داخل الحصر | نافذة في نفس شاشة الحصر | يحمل رقم الحصر تلقائيًا ويعرض المستخلص داخل المساحة نفسها بعد الإنشاء. |
| مراجعة المستخلص واعتماده والفاتورة والطباعة | صفحة | جداول وملخص مالي وروابط مستندات. |
| لوحة الموديول | صفحة | عرض مؤشرات وروابط، بلا نموذج إنشاء قصير. |
| تثبيت أو تحديث الموديول | صفحة إدارية | عملية إدارية منفصلة. |
| مقاولو الباطن وعقودهم وتقاريرهم | غير موجودة في هذا الإصدار | لا توجد لها مسارات أو متحكمات أو نماذج داخل `Modules/Construction` لتحويلها. |

كل نافذة تستخدم مسار الحفظ الأصلي نفسه، مع استجابة JSON عند طلب Ajax فقط. تبقى الروابط المباشرة وإعادة التوجيه التقليدية قائمة. الأخطاء تظهر داخل النافذة، وتُجدد القوائم عبر جلب HTML القسم المعني من المسار الحالي دون إعادة تحميل الصفحة كاملة. على الشاشات الصغيرة تصبح النافذة قابلة للتمرير ضمن ارتفاع الشاشة.
